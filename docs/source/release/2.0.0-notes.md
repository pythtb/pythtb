# PythTB 2.0.0 Release Notes

PythTB 2.0.0 is a major refactor introducing a modular architecture, new functionality, and performance improvements.


## Highlights

- Full package restructuring into modular architecture
- New Berry curvature / Chern / QGT / axion workflows
- Unified mesh handling via `Mesh`
- New `Wannier` workflows
- New predefined model library `pythtb.models`
- Vectorized diagonalization and derivatives
- Optional TensorFlow acceleration


## Breaking Changes

- `TBModel.__init__` now requires a `Lattice` instance
- `spinful` replaces `nspin`
- `solve_one()` and `solve_all()` removed → use `solve_ham()`
- Some methods renamed for clarity
- Eigenvector return shape changed
- Dropped Python < 3.12

See full migration guide: `../migration/1.x_to_2.0.md`

## Added

### Core Architecture
- Modularized package layout:
  - `tbmodel.py`, `wfarray.py`, `mesh.py`, `lattice.py`, `wannier.py`,
    `models/`, etc.
- New classes:
  - `Lattice`, `Mesh`, `Wannier`

### Topology / Quantum Geometry
- `TBModel.velocity()`
- `TBModel.quantum_geometric_tensor()`
- `TBModel.berry_curvature()`
- `TBModel.quantum_metric()`
- `TBModel.chern_number()`
- `TBModel.axion_angle()` (four-curvature formulation)
- `TBModel.local_chern_marker()`

### Wavefunctions
- `WFArray.links()`
- `WFArray.berry_curvature()`
- `WFArray.berry_connection()`
- `WFArray.chern_number()`
- `WFArray.projectors()`
- `WFArray.solve_model()`
- `WFArray.wilson_loop()`

### Models
`pythtb.models`:
- `haldane`, `ssh`, `graphene`, `checkerboard`
- `kane_mele`, `fu_kane_mele`

### Performance
- Vectorized operations across the codebase
- Optional TensorFlow backend

### Documentation / Testing
- Sphinx documentation
- API reference
- pytest test suite
- Type hints throughout

## 🔄 Changed

- `solve_ham()` replaces `solve_one()` + `solve_all()`
- `TBModel.info()` replaces `display()`
- Overlap / projector workflows moved to `WFArray`
- Updated return shapes for eigenvectors, velocity
- `set_onsite()`/`set_hop()` accept strings/callables

---

## 🗑 Deprecated

The following remain temporarily available with warnings:

- `display()` → `info()`
- `get_lat()` → `get_lat_vecs()`
- `get_orb()` → `get_orb_vecs()`
- `solve_one()` → `solve_ham()`
- `solve_all()` → `solve_ham()`

Old class names remain as aliases:
- `tb_model → TBModel`
- `wf_array → WFArray`
- `w90 → W90`

---

## ❌ Removed

- `TBModel.reduce_dim()`
- `WFArray.impose_pbc()`, `impose_loop()`
- `WFArray.solve_on_grid()`, `solve_on_one_point()`
- Python < 3.12
- `setup.py` replaced by `pyproject.toml`
