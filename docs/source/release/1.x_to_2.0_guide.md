# Migration Guide: PythTB 1.x → 2.0

This guide summarizes required user-visible changes when upgrading from
PythTB 1.x to 2.0.


## Key API Changes

### 1) Model initialization

"```python
# Old
model = tb_model(lat, orb, per, nspin=2)
```"

"```python
# New
from pythtb import TBModel, Lattice

lat = Lattice(...)
model = TBModel(lattice=lat, spinful=True)
```"

- `Lattice` now holds geometry + periodicity
- `spinful=True/False` replaces `nspin`


### 2) Hamiltonian solution

"```python
# Old
evals, evecs = model.solve_one(k)
evals, evecs = model.solve_all(kpts)
```"

"```python
# New
evals, evecs = model.solve_ham(kpts)
```"



### 3) Berry / topology APIs

Use new vectorized APIs.

"```python
# Old
phi = wf_array.berry_phase(occ=[0,1], dir=0)
```"

"```python
# New
phi = wf_array.berry_phase(state_idx=[0,1], axis_idx=0)
```"

Other new related methods:
- `WFArray.links()`
- `WFArray.berry_flux()`
- `WFArray.chern_number()`
- `TBModel.berry_curvature()`
- `TBModel.chern_number()`
- `TBModel.quantum_geometric_tensor()`
- `TBModel.axion_angle()`



### 4) Wannier workflows

New class:

"```python
from pythtb import Wannier
```"

Handles projection + localization.



### 5) Parameterized models

`set_onsite` / `set_hop` accept callables/strings.

"```python
model.set_onsite('Δ')
model.set_hop('t*cos(phi)', i, j, R)
```"

Sweep example:

"```python
evals = model.solve_ham(kpts, phi=[0, 0.5, 1.0])
```"



## Renamed Methods

| Old           | New              |
|----------------|------------------|
| `display()`   | `info()`         |
| `get_lat()`   | `get_lat_vecs()` |
| `get_orb()`   | `get_orb_vecs()` |
| `solve_one()` | `solve_ham()`    |
| `solve_all()` | `solve_ham()`    |



## Removed

| Removed       | Replacement |
|---------------|-------------|
| `reduce_dim()` | external handling |
| `impose_pbc()` | automatic via `Mesh` |
| `impose_loop()` | automatic via `Mesh` |
| `solve_on_grid()` | `WFArray.solve_model()` |
| `solve_on_one_point()` | `WFArray.solve_model()` |
| Python < 3.12 | upgrade Python |
| `setup.py`    | `pyproject.toml` |



## Class rename aliases

These still work for backward compatibility:
"```python
tb_model → TBModel
wf_array → WFArray
w90      → W90
```"



## Suggested code update

"```python
# Before
wf = wf_array(...)
wf.solve_on_grid(model)
```"

"```python
# After
wf = WFArray(lattice=lat, mesh=mesh, nstates=n, spinful=True)
wf.solve_model(model)
```"
